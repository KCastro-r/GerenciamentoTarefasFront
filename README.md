# Sistema de Gerenciamento de Tarefas - Front-end (Angular)

## 📌 Sobre o Projeto
Esta é a interface em Angular do sistema de gerenciamento de tarefas com cadastro de usuária. A aplicação permite que a usuária se cadastre, acesse o sistema e gerencie suas próprias tarefas (criar, visualizar, editar e excluir).
